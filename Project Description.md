# Sales Filter Spreadsheet

## Project Overview
This project was carried out to extract and analyze data from a dataset. The project focuses on how the filter function can be used to retrieve records that meet certain criteria given.
Summarily, I applied the FILTER function in Microsoft Excel to filter and extract relevant records from a dataset. I then proceeded to rganize the filtered results for easier interpretation and analysis.

## Business Problem
The dashboard was designed to answer questions such as:
* Return all sales made in Anambra State
*  Return all sales where quantity is greater than 10
*   Return sales where Region is South East and quantity is greater than 5
* Return sales where category is accessories and total sales is greater than a hundred thousand naira
*  Return sales where region is South East, quantity is greater than 5 and total sales is greater than two hundred thousand naira

The Dataset contains information about Sales transactions in some states and regions in Nigeria. Key fields include:
